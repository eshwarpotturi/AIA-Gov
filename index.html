The trader gets the answer, not the data

“Why does my trading desk show a $2 million discrepancy in today's positions?”

An Orchestrating agent answers by asking four specialist agents: Trade, Position, Market Data and Risk. Every call carries the trader's identity through the Gate, which is plain code (no AI) and checks two things: may this agent use this tool, and may this human see this data? Governance wakes only for exceptions. An Auditor attacks the rules, and Compliance signs off every change. AI proposes, Compliance approves, code enforces, and every attack makes the rules stronger.
